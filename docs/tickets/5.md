## What to build

El usuario puede iniciar la demo local, conocer el estado real de QVAC y continuar explorando reglas claramente identificadas cuando la IA falla, sin depender de un modelo específico de GPU.

Demo para confirmar participación en un reto: Panamá, español, USD, datos ficticios y consultas ambulatorias. La especificación completa del padre rige este ticket. Las pruebas se realizan en la API pública de conversación y estimación, frontera confirmada por el usuario.

## Acceptance criteria

- [ ] Mantener inferencia QVAC en loopback y documentar instalación, descarga inicial y ejecución posterior con caché local.
- [ ] Preferir GPU dedicada compatible, luego integrada y CPU compatible; no fijar NVIDIA o RTX 4070 ni asumir compatibilidad universal.
- [ ] Distinguir modelo listo, desconectado, cargando y error según evidencia disponible; no confundir API disponible o preferencia configurada con dispositivo real de inferencia.
- [ ] Mostrar dispositivo real solo con evidencia; si no está expuesto, decirlo. Documentar comprobación mediante diagnóstico y procesos o registros del runtime.
- [ ] Gestionar desconexión, timeout y respuesta inválida sin dejar la interfaz bloqueada ni mostrar resultados obsoletos.
- [ ] Ofrecer modo de reglas explícitamente identificado como sin IA, preservar cálculos deterministas y bloqueo de posible urgencia, y permitir reintento de conexión.
- [ ] No persistir síntomas o conversaciones en registros de aplicación ni enviar datos a servicios de IA externos.
- [ ] Probar fallos y recuperación desde la API pública, con servicio QVAC controlado; verificar manualmente inicio, inferencia real y evidencia de hardware, documentando qué dispositivos se comprobaron realmente.
