# Domain docs

## Estructura
Contexto único: `CONTEXT.md` y `docs/adr/` en la raíz.

## Antes de explorar
Lee `CONTEXT.md` y los ADR relacionados con el área de trabajo.
Si no existen, continúa sin señalar su ausencia ni proponer crearlos.
La skill `domain-modeling` los crea cuando se resuelven términos
o decisiones.

## Vocabulario y decisiones
Usa los términos definidos en `CONTEXT.md`.
Si falta un concepto necesario, señala el vacío para `domain-modeling`.
Expón cualquier contradicción con un ADR existente e identifica
la decisión afectada.
